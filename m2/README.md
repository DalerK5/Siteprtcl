# Журнал испытаний ТС категории M2

Streamlit-приложение для автобусов категории **M2**: загрузили PDF-протокол(ы) → получили заполненный журнал по шаблону `template_m2.xlsx`.

- Streamlit Cloud: тот же репозиторий, ветка `main`, **Main file path** `m2/app.py`.
- Код такой же, как у приложения M3 (`m2_m3/app.py`), отличаются только `CAT = "M2"` и шаблон.
- Строки журнала находятся **по подписям шаблона** (столбец D листа «НЕОПРЕДЕЛ»), поэтому раздел 8 по O’z DSt 35.52
  (топливный бак, служебная дверь классов А/В, запасные двери и окна и т.д.) и блоки массы M2 заполняются в свои строки.
- В шаблоне применены те же исправления, что и в M3: габариты в метрах, поправки 3.27 обнулены, Og'ish вычитается во всех блоках.
