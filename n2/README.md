# Журнал испытаний ТС категории N2

Streamlit-приложение для грузовых автомобилей категории **N2** (3,5–12 т: автовышки, автоцистерны, самосвалы и т.п.):
загрузили PDF-протокол(ы) → получили заполненный журнал по шаблону `template_n2.xlsx`.

- Streamlit Cloud: тот же репозиторий, ветка `main`, **Main file path** `n2/app.py`.
- Код — копия приложения N3 (`n3/app.py`) + выступы дверей/обшивки, зазоры 25–40 mm, пункты бокового ограждения,
  напечатанные в разделе «разбрызгивание». Норма каждого блока в журнале берётся из протокола.

## Шаблон `template_n2.xlsx`

Собран из шаблона M2 (габариты в m, Og'ish вычитается, ППР «не менее» = `1-NORM.DIST`, без цвета, без «п.…»)
по составу шаблона пользователя `N2.xlsx` и протоколов N2. Шапка — как в M2/M3 (с «Состояние ТС», «Двигатель», «Пробег»).
