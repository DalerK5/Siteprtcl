# Журнал испытаний ТС категорий M2–M3 (автобусы)

Streamlit-приложение: загрузили PDF-протокол → получили заполненный журнал `template.xlsx` (лист «НЕОПРЕДЕЛ» + расчётные листы неопределённости).

## Запуск

- Локально: `streamlit run m2_m3/app.py`
- Streamlit Cloud: тот же репозиторий, в поле **Main file path** указать `m2_m3/app.py`.

## Что делает

- ID = название PDF-файла (`1901093.pdf` → «ID № 1901093» в `НЕОПРЕДЕЛ!E1`, скачивается как `1901093.xlsx`); ID можно поправить в поле перед заполнением.
- Марка, модель, категория, VIN, условия испытаний → шапка листа «НЕОПРЕДЕЛ» (D5–D8, D10–D12, D14); номер протокола → `'48-04'!F1` (остальные листы ссылаются на эту ячейку).
- Каждый замер — тройка в колонке E (строки r, r+1, r+2). Среднее тройки **точно** равно результату протокола, разброс берётся из шаблона. Режим «по СР.ЗАНЧ» (в «Шаблон и настройки») подгоняет под протокол среднее с поправкой Og'ish.
- Габариты переводятся из m (протокол) в mm (журнал).
- Блоки, которых нет в протоколе, очищаются.
- Формулы не меняются. Готовые значения формул вписываются в файл, стоит `fullCalcOnLoad="1"`, `calcChain.xml` удаляется (Excel построит его сам).

## Исправлено в шаблоне

- `'48-04'!C163` было числом 1420 — теперь `=AVERAGE(C160:C162)`; `C160:C162` вычитают поправку `C164`, как остальные блоки листа.
- `'ЕЭК ООН № 43'!D22:D24` теперь ссылаются на `НЕОПРЕДЕЛ!E250:E252`, а `E250:E252` — обычные ячейки замеров (раньше были формулы `=82-E254`…).
