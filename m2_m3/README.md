# Журнал испытаний ТС категории M3 (автобусы)

Streamlit-приложение: загрузили PDF-протокол → получили заполненный журнал `template_m3.xlsx` (лист «НЕОПРЕДЕЛ» + расчётные листы неопределённости).

## Запуск

- Локально: `streamlit run m2_m3/app.py`
- Streamlit Cloud: тот же репозиторий, в поле **Main file path** указать `m2_m3/app.py`.

## Что делает

- Можно загрузить сразу несколько PDF (например, 10): каждый обрабатывается отдельно, внизу — сводка по каждому файлу (✅ / ⚠️ / ❌), кнопка «Скачать все журналы (.zip)» и отдельные кнопки на каждый файл; подробности — через выбор файла. Одинаковые ID получают суффикс `_2`, `_3`.

- ID = название PDF-файла (`1901093.pdf` → «ID № 1901093» в `НЕОПРЕДЕЛ!E1`, скачивается как `1901093.xlsx`); ID можно поправить в поле перед заполнением.
- Марка, модель, категория, VIN, условия испытаний → шапка листа «НЕОПРЕДЕЛ» (D5–D8, D10–D12, D14); номер протокола → `'48-04'!F1` (остальные листы ссылаются на эту ячейку).
- Каждый замер — тройка в колонке E (строки r, r+1, r+2). По умолчанию «СР.ЗАНЧ» (среднее с поправкой Og'ish) **точно** равно результату протокола; в «Шаблон и настройки» можно переключить на «среднее самих замеров = протоколу».
- Габариты — в метрах, как в протоколе (если протокол в mm — переводится в m). Блок габаритов шаблона переведён в m: образцы, пределы (13.5 / 2.55 / 4), поправка 0.59 mm → 0.00059 m.
- Блоки, которых нет в протоколе: замеры очищаются, а среднее, решение и неопределённость показываются пустыми (формулы обёрнуты в IF(COUNT(…)=0;"";…), при ручном вводе замеров снова считают).
- Неопределённость: тройка подбирается так, чтобы U в колонке F (по формулам шаблона) после округления совпадала с протоколом, а среднее осталось равным протоколу. Если нужно — у замеров добавляются знаки после запятой. Если формулы шаблона такого U дать не могут (минимум ≈ 1.96·UB, скачки из-за округления степеней свободы в TINV) — в выходном файле уменьшается UB этого блока до ближайшего «круглого» значения (=a/2), при котором U совпадает; такие изменения показываются списком (шаблон не меняется).
- Формулы не меняются. Готовые значения формул вписываются в файл, стоит `fullCalcOnLoad="1"`, `calcChain.xml` удаляется (Excel построит его сам).

## Исправлено в шаблоне

- `'48-04'!C163` было числом 1420 — теперь `=AVERAGE(C160:C162)`; `C160:C162` вычитают поправку `C164`, как остальные блоки листа.
- Подпись аптечки (`НЕОПРЕДЕЛ!D327`) — без «mm».
- `'ЕЭК ООН № 43'!D22:D24` теперь ссылаются на `НЕОПРЕДЕЛ!E250:E252`, а `E250:E252` — обычные ячейки замеров (раньше были формулы `=82-E254`…).
- Во всех блоках замеры на расчётных листах теперь вычитают свою поправку «Og'ish» (раньше в блоках «ГОСТ 30593-2015», «Номерный знак» и части «О’zDSt 35.36 2010» не вычитали).

## Проверить значения поправок

Значения «Og'ish» не менялись, но часть выглядит подозрительно: было `'ГОСТ  30593-2015 '!D58, D74, D90, D106, D123` = 3.27 (скорость воздуха, температура, влажность); `'Номерный знак'!B11, B25` = 0.59 (углы). Поправки 3.27 обнулены (давали, например, влажность 38 → 34.73). Значения 0.59 оставлены.
