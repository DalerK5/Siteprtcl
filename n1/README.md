# Журнал испытаний ТС категории N1

Streamlit-приложение для грузовых автомобилей категории **N1**: загрузили PDF-протокол(ы) → получили заполненный журнал
по шаблону `template_n1.xlsx`.

- Streamlit Cloud: тот же репозиторий, ветка `main`, **Main file path** `n1/app.py`.
- Код — копия приложения M2/M3 (`m2_m3/app.py`) плюс правила N1: наружные выступы (O’z DSt 35.61), выбросы CO/CH
  (ГОСТ 17.2.2.03-87), внешний шум в трёх режимах, расположение педалей (E, H, J), короткие формулировки
  вентиляции/кондиционирования, категория N1, марка «marka X Y,» и «Грузовой автомобиль X, модели Y,».
- Строки журнала находятся **по подписям шаблона** (столбец D листа «НЕОПРЕДЕЛ»).

|---|---|---|

| 8 | 317–331 | передние противотуманные фары (48-04) |
| 9 | 332–336 | зеркала класса 5 и 6 (Правила № 46) |
