# Журнал сертификационных испытаний ТС

Веб-приложение для автоматического заполнения рабочего журнала сертификационных испытаний.

## Для сотрудников

- Работает на компьютере и телефоне
- Загружаете PDF-протокол → получаете заполненный Excel
- Формулы и форматирование сохраняются

## Файлы

- `app.py` — основное приложение
- `requirements.txt` — зависимости
- `template.xlsx` — шаблон журнала

## Категория M1 (`app.py` в корне)

- Можно загрузить сразу до 10 PDF: сводка по каждому файлу, «Скачать все журналы (.zip)» и отдельные кнопки.
- ID = название PDF-файла: «ID № 2007212» пишется в ячейку `K2` (справа от даты), файл скачивается как `2007212.xlsx`.
- Среднее каждой тройки = результату протокола; неопределённость (строка «Расш.неопр.») после округления = неопределённости протокола. Если погрешность прибора UB в шаблоне не позволяет — в файле уменьшается UB этого блока (показывается списком).
- Пустые блоки (нет в протоколе): среднее и неопределённость пустые, без #DIV/0!.
