# Журналы испытаний ТС — общее приложение

Одна ссылка для всех категорий: сверху выбор категории (M1, M2, M3, N1, N2, N3, O4), ниже — приложение этой категории.
Код и шаблоны не дублируются: берутся из папок категорий (`app.py` + `template.xlsx`, `m2/`, `m2_m3/`, `n1/`, `n2/`, `n3/`, `o4/`)
— каждое приложение вызывается как `main(embedded=True)` (без своего заголовка).

- Streamlit Cloud: ветка `main`, **Main file path** `all/app.py`.
- Ссылка сразу на категорию: `…/?cat=N3`.
- При смене категории результаты и заменённый шаблон сбрасываются, загруженные PDF остаются.
- Установка на телефон: iPhone — Safari → «Поделиться» → «На экран Домой»; Android — Chrome → «Добавить на главный экран».
