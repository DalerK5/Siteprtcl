# Журнал испытаний ТС категории N3

Streamlit-приложение для грузовых автомобилей категории **N3** (седельные тягачи, шасси со спецтехникой): загрузили
PDF-протокол(ы) → получили заполненный журнал по шаблону `template_n3.xlsx`.

- Streamlit Cloud: тот же репозиторий, ветка `main`, **Main file path** `n3/app.py`.
- Код — копия приложения O4 (`o4/app.py`: ЗПЗ, разбрызгивание, боковое ограждение, шапка по подписям) + правила N1
  (наружные выступы, выбросы, шум, педали) + ППЗУ. Норма каждого блока в журнале берётся из протокола.

## Шаблон `template_n3.xlsx`

Собран из шаблона M2 (габариты в m, Og'ish вычитается, ППР «не менее» = `1-NORM.DIST`, без цвета, без «п.…»)
по составу шаблона пользователя `N3_3.xlsx` и протоколов N3. Шапка без строк «Состояние ТС», «Двигатель», «Пробег».
