# Журнал испытаний ТС категории O4

Streamlit-приложение для прицепов и полуприцепов категории **O4**: загрузили PDF-протокол(ы) → получили заполненный журнал
по шаблону `template_o4.xlsx`.

- Streamlit Cloud: тот же репозиторий, ветка `main`, **Main file path** `o4/app.py`.
- Код — копия приложения M2/M3 (`m2_m3/app.py`) плюс правила O4 (`classify_o4`): ЗПЗ, защита от разбрызгивания,
  боковое защитное устройство; категория O. Норма каждого блока в журнале берётся из протокола.

## Шаблон `template_o4.xlsx`

Собран из шаблона M2 (габариты в m, Og'ish вычитается, ППР «не менее» = `1-NORM.DIST`, без цвета, без «п.…»)
по составу шаблона пользователя `O4_2.xlsx`:

| Раздел | Строки | Что |
|---|---|---|
| 1 | 19–163 | Правила № 48-04: задний ход, габаритные (перед/зад), стоп-сигнал, задние указатели поворота, задний ПТФ, световозвращатели (зад/перед) |
| 2 | 164–178 | габариты: длина ≤ 12, ширина ≤ 2,55, высота ≤ 4 m |
| 3 | 179–198 | номерной знак: ±3°, ±5°, ≤ 1200, ≥ 300 mm |
| 4 | 199–213 | O’z DSt 35.58 ЗПЗ: просвет ≤ 550, укорочение с каждой стороны ≤ 100, высота сечения ≥ 100 mm |
| 5 | 214–233 | ТР Прил. 4 §10 разбрызгивание: шина — боковина ≤ 75, глубина боковины ≥ 45, брызговик нижний край ≤ 200, брызговик — шина ≤ 300 mm |
| 6 | 234–263 | O’z DSt 35.73 боковое ограждение: задний конец ≤ 30, радиус ≥ 2,5, между полосами ≤ 300, высота полос ≥ 100, передний край ≤ 300, нижний край ≤ 550 mm |
