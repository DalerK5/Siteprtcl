# Журнал испытаний ТС категории O4

Streamlit-приложение для прицепов и полуприцепов категории **O4**: загрузили PDF-протокол(ы) → получили заполненный журнал
по шаблону `template_o4.xlsx`.

- Streamlit Cloud: тот же репозиторий, ветка `main`, **Main file path** `o4/app.py`.
- Код — копия приложения M2/M3 (`m2_m3/app.py`) плюс правила O4 (`classify_o4`): ЗПЗ, защита от разбрызгивания,
  боковое защитное устройство; категория O. Норма каждого блока в журнале берётся из протокола.

## Шаблон `template_o4.xlsx`

Собран из шаблона M2 (габариты в m, Og'ish вычитается, ППР «не менее» = `1-NORM.DIST`, без цвета, без «п.…»)
по составу шаблона пользователя `O4_2.xlsx` и протоколов O4. В шапке нет строк «Состояние ТС», «Двигатель», «Пробег».

| Раздел | Строки | Что |
|---|---|---|
| 1 | 16–180 | Правила № 48-04: задний ход, габаритные (перед/зад), стоп-сигнал, указатели поворота (перед/зад), задний ПТФ, световозвращатели (зад/перед) |
| 2 | 181–195 | габариты: длина ≤ 12, ширина ≤ 2,55, высота ≤ 4 m |
| 3 | 196–215 | номерной знак: ±3°, ±5°, ≤ 1200, ≥ 300 mm |
| 4 | 216–225 | боковые световозвращатели: ≤ 1500, ≥ 250 mm |
| 5 | 226–245 | O’z DSt 35.58 ЗПЗ: просвет ≤ 550, укорочение ≤ 100, высота сечения ≥ 100, радиус концов ≥ 2,5 mm |
| 6 | 246–285 | ТР Прил. 4 §10 разбрызгивание: шина — боковина ≤ 75, глубина боковины ≥ 45, высота боковины ≥ 100, между шинами < 250, нижний край брызговика ≤ 200, брызговик — шина ≤ 300, устройство от края брызговика ≥ 100, отклонение брызговика ≤ 100 mm |
| 7 | 286–320 | O’z DSt 35.73 боковое ограждение: от габарита ≤ 120, радиус ≥ 2,5, между полосами ≤ 300, высота полос ≥ 100, передний край ≤ 300, задний край ≤ 300, нижний край ≤ 550 mm |
